# Зміни

Релізи — теги `vX.Y.Z` (нотатки GitHub генеруються з PR). Тут — зміни, які потребують дій від розгортань.

## Невипущене

- **Мови окремо на кожен бренд у розгортанні без префіксів** (`app.locale_prefix: false`). Адмінка бренду: замість
  «Мови сайту» — «Головна мова» (без префікса) і галочки «Додаткові мови» (під `/<мова>/`). Міграцій нема, бренди з
  однією мовою працюють як раніше. Дія **до викладки**: перевірити `SELECT slug, locales FROM service_site` — бренд з
  кількома збереженими мовами отримає адреси `/<мова>/`, а головною стане перша збережена (було — перша за `app.locales`).
  Тексти додатковою мовою треба заповнити. Авто-301 пишуться для всіх мов бренду (і `en`), зрізання зайвого query
  діє й під префіксом додаткової мови.

- **Підтвердження Google Search Console через DNS TXT з адмінки бренду.** «Налаштування сайту» → SEO →
  «Google: підтвердження DNS (TXT)» (`seo.google_dns_verification`, до 5 значень; рядок `google-site-verification=…`
  зводиться до значення). При збереженні рушій ставить TXT на апекс бренду в Cloudflare і прибирає лише свої записи;
  стан по домену, «Стан у Cloudflare» і «Перевірити в DNS» — під списком налаштувань. Як підключити — `docs/site-ops.md`,
  «Підтвердження сайту в Google Search Console через DNS TXT».
  Дія: власник створює Cloudflare API token з правами лише **Zone:Read + DNS:Edit** і **лише на зони брендів цього
  розгортання** (окремий на розгортання) і кладе в `shared/.env.local` як `CLOUDFLARE_DNS_TOKEN=…` (600). Без токена все
  працює, TXT додається вручну за рядком з адмінки.
- **Файлів підтвердження на сайтах більше нема.** Прибрано `public/google3cc17ecbb1f93a59.html` (з v0.9.31 віддавався на
  всіх сайтах усіх розгортань, тобто одне ім'я файла на всі домени); `/google<hex>.html` і `/BingSiteAuth.xml` → 404.
  Міграція `Version20261120100000` видаляє рядки налаштувань файлового способу.
  Дія для сайту, підтвердженого цим файлом: **до викладки** додати в GSC тим самим акаунтом ресурс «Домен», поставити TXT
  вручну в DNS і підтвердити; після викладки вписати те саме значення в поле (дубля рушій не створить). Порядок —
  `docs/site-ops.md`, «Перехід сайту, підтвердженого файлом». Bing — імпортом з GSC.
